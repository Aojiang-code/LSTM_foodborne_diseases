# LSTM_foodborne_diseases
本研究采用长短期记忆网络（LSTM）对宁海县2016至2024年食源性疾病发病数据进行建模与预测。LSTM是一种特殊的循环神经网络（RNN），通过其独特的门控机制有效解决了传统RNN在处理长序列数据时的梯度消失问题，能够捕捉时间序列中的长期依赖关系。在本研究中，LSTM模型结合了气象数据（温度、湿度、降水量、风速和紫外线指数）及历史发病数据，通过数据标准化和适当的网络结构设计（包括LSTM层、Dropout层和Dense层），对未来的发病人数进行了高精度预测。模型训练过程中，通过多次迭代优化，确保了稳定性和预测能力。测试集上的性能指标（MAE、MSE、RMSE、MAPE和R²）表明模型预测精度高，为食源性疾病的防控提供了有力支持。
