# 气象数据与食源性疾病就诊人数预测模型

本代码实现了一个基于长短期记忆网络（LSTM）的时间序列预测模型，用于根据气象数据（温度、湿度、降水量、风速和紫外线指数）预测食源性疾病的就诊人数。代码的主要流程包括数据预处理、模型构建、训练与评估，以及结果可视化。

## 数据预处理
1. **数据加载与日期处理**：从CSV文件中加载数据，并将日期列转换为日期格式。
2. **按月汇总数据**：按年份和月份分组，计算每个月的气象数据均值和就诊人数总和。
3. **特征与目标变量分离**：将气象数据作为特征，就诊人数作为目标变量。
4. **数据划分**：将数据划分为训练集（2024年之前）和测试集（2024年）。
5. **数据标准化**：使用`MinMaxScaler`对特征数据进行归一化处理。
6. **数据重塑**：将数据转换为LSTM所需的三维形状 `[samples, timesteps, features]`。

## 模型构建与训练
1. **模型架构**：构建一个包含LSTM层、Dropout层和Dense输出层的序列模型。
   - LSTM层：50个神经元，激活函数为ReLU。
   - Dropout层：丢弃率为0.2，用于防止过拟合。
   - Dense层：1个输出神经元，用于预测就诊人数。
2. **模型编译**：使用Adam优化器和均方误差（MSE）作为损失函数。
3. **模型训练**：训练200个周期，每批次10个样本，并设置20%的数据用于验证。

## 模型评估与结果可视化
1. **预测与反标准化**：在测试集上进行预测，并将预测结果反标准化。
2. **性能指标计算**：计算均方误差（MSE）、均方根误差（RMSE）、平均绝对误差（MAE）、平均绝对百分比误差（MAPE）和决定系数（R²）。
3. **结果可视化**：
   - 绘制实际值与预测值的对比图，展示模型的预测效果。
   - 绘制训练过程中的训练损失和验证损失曲线，评估模型的训练效果。

通过上述流程，该代码能够基于气象数据对食源性疾病的就诊人数进行有效预测，并通过多种性能指标和可视化图表评估模型的性能。
